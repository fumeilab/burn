# Burn — LLM Cost Calculator

Compare pricing across every major LLM provider. Input your usage, see what you'll pay.

**Live:** [burn.fumeilab.com](https://burn.fumeilab.com)

## What it does

- Current pricing for 20+ models from OpenAI, Anthropic, Google, Meta, Mistral, DeepSeek, and Qwen
- Cost calculator: input your monthly token usage, see estimated costs ranked cheapest-first
- Filter by provider, sort by any column
- Side-by-side comparison mode for 2-3 models

## Tech

Single HTML file. No dependencies, no build step. Open `index.html` in a browser.

## Pricing data

Last updated: March 2026. Prices sourced from official provider pricing pages.
